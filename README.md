# FerryBoss
FerryBoss: босс на Паромном терминале с гранатомётом в руках. Преследует игроков, бьёт током и обнуляет еду и воду, призывает свиту с ракетными револьверами. На 50% здоровья переходит во вторую стадию: защита от пуль и взрывов растёт, урон и скорость тоже. Маркер на карте, лут в мешках, таймер респавна, вся настройка в конфиге. Автор: Shturman
